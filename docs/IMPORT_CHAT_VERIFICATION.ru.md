# Импорт и чат: исправления и проверка 2026-10-01

## Импорт Desktop

- Выбор нескольких HTML/HTM-файлов доступен прямо на экране импорта. Поддерживается объявленная в HTML кодировка, включая Windows-1251.
- В узком окне отдельные вкладки «Посты», «Редактор», «Сохранение»; в широком — три панели. Основные действия доступны без прокрутки длинного редактора.
- Выбранные записи сохраняются в личные JSON-файлы и сразу попадают в библиотеку. Повторный импорт обновляет тот же ID, не создаёт дубль. Публичный каталог не изменяется.
- Исправлены выбор ещё не открытых записей, исправление ошибок валидации, пропуск записи, повторное открытие файлов в существующей вкладке и двойная стартовая загрузка.
- Это импорт HTML-постов; выбор произвольного JSON-файла в этой вкладке не добавлен. Запись файлов и базы не является общей транзакцией: при ошибке базы сохранённые JSON остаются доступны для повторного импорта.
- Android не показывает импорт независимо от ширины окна.

## Чат по поведению Android

- Автоматическое создание чата при первой отправке; защита от двойной отправки, работающая остановка и сохранение частичного ответа.
- Повтор ответа без дублирования пользовательского сообщения. Редактирование пользовательского сообщения заменяет последующие ответы и запускает генерацию заново.
- Черновики текста и вложений сохраняются отдельно для каждого чата. Параметры нового чата применяются уже к первой генерации.
- Копирование, выбор модели, обновление моделей, прокрутка и закрытие компактного бокового меню исправлены.
- Вложения Desktop: изображения и текстовые файлы. PDF/DOC не поддерживаются; неподдерживаемый файл вызывает явную ошибку.
- Общие ChatComposer и ChatBubbleSurface используются Android/Desktop. Платформенные адаптеры навигации и часть содержимого экранов пока остаются отдельными.
