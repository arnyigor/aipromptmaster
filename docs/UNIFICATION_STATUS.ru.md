## Итерация 2026-11-13: стабильность чата, модели и настройки

Проверено на Android 12 (AVD) и на ONEPLUS A6013 (Android 11), данные реального устройства сохранены.

### Room
- **v9**: `messages.reasoning` + `messages.reasoning_chars` — размышления модели сохраняются (троттлинг 400 мс) и восстанавливаются после перезапуска приложения.
- **v10**: `models` получила **составной ключ** `(providerId, id)`; legacy-строки с `providerId=''` нормализуются в `openrouter`. Миграция прогнана на реальной БД телефона (8 → 10) без потери данных.
- Desktop: БД **v5**, `chat_messages.reasoning`; reasoning приходит из `delta.reasoning_content` и показывается в `ThinkingBlock`.

### Чат
- Ответ модели без первого токена показывает анимированный индикатор; при наличии reasoning вместо него — сворачиваемый блок «Думает… · N симв.» (в развёрнутом виде весь текст со скроллом).
- Автоскролл: отправка всегда прокручивает вниз; ответ догоняется, только если пользователь не отлистал историю вверх.
- Заголовок чата снова показывает **имя модели** с шевроном (тап открывает выбор); отдельный чип убран. Имя сокращается (`shortModelName`): путь к `.gguf` → имя файла.
- В шапке ответа — измеренные метрики: `модель · 8.0 с · 98 симв./с`. Оценка «Примерно N токенов» удалена.
- Компактная типографика markdown (`compactMarkdownTypography`): заголовки больше не рендерятся как 45–57 sp.
- Быстрый ввод в поиске промптов и моделей больше не теряет и не переставляет символы (локальное состояние поля).

### Провайдеры и модели
- Пресет «OpenRouter — бесплатные» (`openrouter/free`).
- Список моделей читается из БД по **всем** провайдерам, с группировкой и заголовками; фильтр-чипы по провайдеру.
- Выбор модели переключает активный профиль на её владельца; избранное и доступность обновляются по паре `(providerId, id)`.
- Устаревшие модели провайдера удаляются при обновлении списка, но избранные и выбранная сохраняются.
- Ошибки провайдера показываются человеческим текстом: 401/403/403-Cloudflare/404/429/5xx (`providerHttpMessage`).

### Настройки и синхронизация
- Отдельная вкладка **«Синхронизация»** с карточкой каталога и статусом.
- Этапы `CHECKING → DOWNLOADING → VALIDATING → IMPORTING → DONE` и прогресс: проценты по байтам при известном `Content-Length`, иначе индикатор без процентов.

### Ограничения
- Чат через OpenRouter с мобильной сети и эмулятора получает `403 Access denied by security policy` (Cloudflare) — это сеть, а не код. Локальный OpenAI-совместимый сервер работает.
- Байтовый прогресс синхронизации невозможен без `Content-Length`.
- Reasoning не передаётся в контекст следующего запроса (по замыслу).
