# Решение по AIPromptMasterCompose

Основным остаётся aipromptmaster, как указал пользователь. Вторая копия сохраняется в проверенном bundle и архиве текущих файлов; активные Android-исходники из неё не переносятся поверх основного проекта.

Проверены наборы отслеживаемых source/resource/config файлов, SHA-256, полный diff app/src и определения из ast-index обеих копий. В Compose нет уникальных Kotlin source-файлов. Уникальные ресурсы — старые mipmap launcher icons. Их сохраняет архив; актуальные иконки основного проекта остаются.

В ast-index найдены три определения методов, присутствующие только в Compose:

| Метод | Результат usages | Решение |
|---|---|---|
| buildMessagesForApi | Два обращения в целиком закомментированном LLMInteractorTest | Не восстанавливать неиспользуемую реализацию |
| runStreamingWithFiles | Нет вызовов | Не переносить |
| getHistoryWithTokenLimit | Только из buildMessagesForApi | Архивировать с исходником; отдельно проектировать ограничение истории по требованиям чата |

Различия действующих интерфейсов ILLMInteractor/IOpenRouterRepository — форматирование, активный API не потерян. ChatViewModel отличается комментарием. Основной проект расширяет models availability/rating, схемы Room до версии 8, UI отображения системных сообщений, тему и диагностику API. Старые схемы 4–6 не подменяют схемы основного проекта; их совместимость оценивается отдельно по миграциям.

Существенное уточнение baseline: LLMInteractorTest.kt целиком закомментирован в обеих копиях и не выполняется. На текущем шаге Android unit suite содержит 26 FileRepository tests, 6 новых import safety tests и один Example test. Поэтому успешный unit suite не подтверждает все сценарии чата. Отдельный chat regression suite остаётся последующей задачей.

Полный diff сохранён в приватной резервной копии `android-source-comparison.diff`, таблица файлов — `aiprompts/docs/ANDROID_COMPARISON.md`. Папка Compose пока физически не удалена; завершение архивирования входит в пункт очистки legacy.
