# UI: принятые решения и источники, 2026-10-01

За основу взяты существующие Android `ModelsScreenContent` и `ChatScreen`: одно основное содержимое, поиск над списком, горизонтальная полоса фильтров, сортировка в меню, отдельная область ввода чата. Изменения проверяются на реальных composable через PNG; computer-use не используется.

## Применено

- Общая тема и адаптивная оболочка вместо отдельных каркасов Android/Desktop.
- `ModelPickerControls` в shared-ui: Android и Desktop используют один поиск, горизонтальные фильтры и меню сортировки. Фильтры не сжимаются до отдельных букв.
- Поиск отображает ввод сразу. Debounce 300 мс применяется к выдаче Android, а не к тексту поля.
- Список моделей занимает оставшееся место и прокручивается независимо от поиска. В компактном окне выбор модели занимает весь экран; в более широком — ограниченный по ширине диалог.
- У чата один заголовок. Дублирующий индикатор модели над вводом убран; поле ввода не содержит длинной подсказки о клавишах.
- Параметры являются дополнительной панелью: на узком окне открываются полностью в закрываемом и прокручиваемом bottom sheet, на широком показываются рядом. Три панели требуют не менее 1080 dp доступной ширины, чтобы оставить чату 360 dp.
- Для параметров используются понятные русские подписи и семантические названия интерактивных элементов. Вместо декоративных десятков точек — непрерывные слайдеры в прежних диапазонах.
- Кнопка остановки генерации вызывает существующий обработчик отмены вместо прежнего TODO.
- Навигационные компоненты и владельцы черновика/чата сохраняются вне адаптивных макетов. Неактивная Desktop-страница не создаёт модальные окна поверх активной.
