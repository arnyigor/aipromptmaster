# Исправления по аудиту — 9 октября 2026

Исходный аудит: [AUDIT_2026-10-09.ru.md](AUDIT_2026-10-09.ru.md), commit ab4f894. Этот документ описывает последующие изменения, а не заменяет исходные результаты аудита.

## Выполнено

- [x] Android/Desktop: SSE разбирается по кадрам, поддерживает heartbeat, `data:` без пробела, многострочные данные. EOF без `[DONE]`/finish_reason и ошибка внутри HTTP 200 больше не считаются успешным ответом. `length`/content_filter обозначают незавершённый ответ.
- [x] Частичный ответ сохраняется при ошибке: Desktop — Failed; Android — текст с пометкой «Ответ прерван». Пустой placeholder удаляется. Остановка и повторная генерация проверяются отдельно.
- [x] Desktop: название, system prompt, параметры и модель обновляются отдельными SQL UPDATE. Параллельные изменения больше не перезаписывают соседние поля.
- [x] Модель в шапке и параметрах совпадает с моделью текущего чата. Новые чаты закрепляют выбранную модель/провайдера; смена провайдера требует явного выбора модели для продолжения старого чата.
- [x] Desktop schema 4: nullable provider_id; миграции реальных старых схем 1–3 проверены. Старые чаты сохраняют совместимость.
- [x] Подтверждение удаления чата, просмотр архива и восстановление. Черновик удаляется только вместе с подтверждённым удалением чата.
- [x] История получает preview и суммы токенов из БД, без загрузки всех сообщений всех чатов. Параметры используют сообщения текущего чата.
- [x] Desktop отображает Markdown, списки и код существующим renderer, как Android. Скриншоты проверены при 320/1440 px; также сгенерированы 360/720, светлая/тёмная тема и настройки с увеличенным шрифтом.
- [x] Общая политика request body для probe, чата и улучшения промпта. Канонические OpenAI/OpenRouter endpoint используют max_completion_tokens; совместимые локальные серверы — max_tokens. Для известных reasoning-семейств не отправляются temperature/top_p. Это консервативная политика, не полный каталог возможностей всех провайдеров.
- [x] Контекст ограничивается бюджетом с резервом ответа/system prompt. Оценка приблизительная, не tokenizer. Последнее слишком большое сообщение отклоняется с объяснением.
- [x] Desktop: до 8 вложений/20 МБ суммарно, изображение до 10 МБ, текст до 2 МБ; изображения уменьшаются до 2048 px, слишком большое разрешение отклоняется до декодирования. Ошибка изображения не заменяется молча обычным текстом. Имена копируемых файлов ограничены папкой вложений.
- [x] Зашифрованные Preferences: большие значения сохраняются частями, Unicode не режется посередине surrogate pair. Manifest переключается после записи всех частей; ошибка сохраняет старое поколение. Cipher создаётся для каждой операции; внутренние ключи скрыты из Settings.keys/size.
- [x] GitHub sync: сохраняется стадия незавершённой операции, после перезапуска показывается необходимость повторного предпросмотра. Проверены сбои после обновления GitHub и после локального apply/перед baseline; повтор не требует повторной публикации уже совпадающих данных. Показывается время успешной синхронизации. Промпты создаются локально как раньше.
- [x] CI запускает весь offline Desktop suite. Debug installer запрещён на этапе конфигурации; неожиданный отказ сохраняет/печатает отдельный guard log.
